# Security policy

Please report security issues privately through
[GitHub's private vulnerability reporting](https://github.com/everypinio/everytestpoint/security/advisories/new).
Do not include confidential PCB files, credentials, or customer data in a public issue.

The latest released version is supported. General bugs and feature requests belong in the public
[issue tracker](https://github.com/everypinio/everytestpoint/issues).
